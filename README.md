# lab

Изолированные стенды для тренировки и разбора: веб-цели, сетевой сенсор, SIEM Wazuh
и песочница без сети.

## Состав

| Профиль | Что поднимается | Порт |
|---|---|---|
| `web` | OWASP Juice Shop, DVWA | 127.0.0.1:3000, 127.0.0.1:8081 |
| `net` | Zeek для офлайн-разбора pcap | — |
| `sandbox` | Debian без сети для недоверенных файлов | — |
| SIEM | Wazuh single-node из `vendor/wazuh-docker` | 443, 1514, 55000 |

## Быстрый старт

```bash
make vendor     # клонировать wazuh-docker (пин v4.14.9)
make up         # веб-цели
make siem       # Wazuh single-node
make down       # погасить всё
```

## Правила безопасности

1. Все порты публикуются только на `127.0.0.1` — стенд не виден в локальной сети.
2. Недоверенные файлы и малварь — только профиль `sandbox` (сеть отключена).
3. Никаких реальных доменов и адресов в конфигах: только RFC 5737 и `.test`.
4. `make reset` удаляет тома и логи; перед этим сохрани доказательства в `ops`.
5. Стенд не подключается к корпоративной сети и не содержит реальных данных.

## Структура

```
compose.yaml          # цели и песочница
scripts/clone-vendor.sh  # пин вендорных репозиториев
scripts/lab.sh        # обёртка: up/down/siem/status/reset
pcaps/                # входные pcap (не коммитим большие)
logs/                 # выход Zeek/Suricata (gitignored)
samples/              # недоверенные сэмплы (gitignored)
```

## Проверка

```bash
docker compose config -q   # валидность compose
shellcheck scripts/*.sh    # скрипты
```
